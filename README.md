# 书间花园 · Book Bloom Garden

让读过的书，在花园里开花。一个可以离线运行、无需安装依赖的电子阅读花园。

## 想法

- 读完一本书 → 书变成种子。
- 写下一段书评 → 种子发芽。
- 书评获得共鸣 → 植物开花。

希望把阅读记录变成一个可以照料、可以分享的小小世界，而不是阅读数量排行榜。

## 马上体验

下载本项目，双击 `index.html`，用现代浏览器打开即可。无需账号、服务器或 API 密钥。

也可在项目目录运行 `python3 -m http.server 8000`，打开 `http://localhost:8000`。

点击“种下一本读完的书”，填写书名；点击植物写书评并保存，再点击“模拟一个赞”体验开花。

## 当前版本

已实现：种书、书评发芽、模拟点赞开花、植物动画、移动端布局、本地保存、JSON 导出备份、减少动画偏好适配。

**这是个人体验原型，不是多人社交产品。** 点赞是模拟操作；花朵画面最多显示九朵，统计保留全部数量。数据存放于当前浏览器的 localStorage，不会上传服务器，不同浏览器、设备和网址之间不会同步。清除浏览器数据可能丢失记录，请先导出备份。当前没有导入备份功能。

线上演示暂不作为稳定入口：原托管地址曾反复出现访问拦截。下载运行不依赖该地址。

## 自己部署

这是纯静态单页，可部署到任意支持 HTML 的静态托管平台。GitHub Pages 可选择从 `main` 分支根目录发布；最终是否可用及访问速度取决于访问者所在网络。无需填写任何环境变量。

## 给开发者和 AI 的技能

`skills/book-bloom-garden/SKILL.md` 包含产品规则、状态转换、实现约束和验证方法。支持 SKILL.md 的代理可读取它继续开发；也可把其中的说明作为开发任务上下文。
